# PasteBin — сервис для обмена текстом с истекающими ссылками

**PasteBin** — это веб-приложение для быстрого обмена текстовыми заметками.  
Пользователь может создать заметку, получить на неё короткую ссылку, поделиться ею с другими.  
Заметки автоматически удаляются через заданное время (TTL).  
Проект демонстрирует полноценную production‑архитектуру: авторизация через JWT, кэширование в Redis, раздельный фронтенд и бэкенд.


## Ключевые сценарии продукта

- **Создание заметок** — пользователь пишет текст, задаёт время жизни (TTL), получает уникальную ссылку вида `/pastes/ABC123`.
- **Публичный доступ** — любой человек может открыть заметку по ссылке (без авторизации).
- **Истечение заметок** — по истечении TTL заметка автоматически удаляется при первом запросе.
- **Личный кабинет** — пользователь видит все свои активные заметки, может их редактировать или удалять.
- **JWT‑авторизация** — регистрация, логин, refresh‑токены, logout.

---

## Архитектура

Проект построен как **два независимых сервиса**, объединённых в одном репозитории:

- **Backend API (Java + Spring Boot)** — REST API с JWT‑аутентификацией, бизнес‑логикой и кэшированием.
- **Frontend HTML + CSS + JS** — пользовательский интерфейс с динамической загрузкой данных.


## Технологический стек

### Backend

- **Java 21** + **Spring Boot 4**
- **Spring Security** + **JWT** — аутентификация и авторизация
- **Spring Data JPA** + **Hibernate** — работа с базой данных
- **MySQL** — основное хранилище
- **Redis** — кэширование популярных заметок
- **Lombok** — сокращение copypaste‑кода и повышение читаемости
- **Maven** — сборка и управление зависимостями

---

## Реализация

### Graceful shutdown и управление ресурсами

Spring Boot автоматически управляет жизненным циклом приложения, корректно закрывая соединения с БД и Redis при остановке.

### Слоистая архитектура

- **Controller** — принимает запросы, валидирует DTO, возвращает ответы.
- **Service** — бизнес‑логика, транзакции, работа с кэшем.
- **Repository** — слой доступа к данным (Spring Data JPA).

### Кэширование

- **@Cacheable** — популярные заметки кэшируются в Redis.
- **@CacheEvict** / `RedisTemplate` — инвалидация кэша при обновлении или удалении.
- Сокращение времени ответа для публичных запросов до 5‑10 мс.

### Авторизация

- **JWT** (Access + Refresh токены).
- **Фильтр** `JwtAuthenticationFilter` проверяет каждый запрос.
- **Authentication** — доступ к данным текущего пользователя в контроллерах.

### Таймзоны и истечение TTL

- Каждая заметка хранит `expires_at`.
- Истекшие заметки удаляются при первом запросе, реализуя ленивое удаление и экономя ресурсы.
- `TTL` в минутах задаётся пользователем при создании.
